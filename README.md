# Pulso Options Analyzer — WEB5.0 V3.34

Opciones (default), acciones y ETF. Large cap, weeklies ≤7 días, comisión IBKR.

**Versión del sitio:** `WEB5.0 - V3.23` (se ve en el header, junto al logo RE).

```bash
git clone https://github.com/Roberto6669/pulso-opciones.git
cd pulso-opciones
grep APP_VERSION src/components/brand.tsx
# debe decir: WEB5.0 - V3.23
npm install
npm run dev
```

Si ya tenías la carpeta y sigue en v1.0, no hagas pull sobre archivos viejos. Borra y clona de nuevo:

```bash
rm -rf "$DEST"
git clone https://github.com/Roberto6669/pulso-opciones.git "$DEST"
```
